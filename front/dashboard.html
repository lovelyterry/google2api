关于 google2api 项目信息

高性能开源 Google Gemini 与 Antigravity 代理转接网关，统一为标准的 OpenAI / Claude / Gemini API 协议

📋
项目简介与架构说明

google2api 是一个专为开发者打造的高性能 API 网关代理工具。能够将 Google Gemini 和 Google Antigravity 统一无缝转换为标准的 OpenAI (v1)、Claude 和 Gemini Native API 格式，支持多账户智能负载均衡轮换、实时日志流监控与动态模型重定向。

🔗 开源 GitHub 仓库： ⭐ GitHub - lovelyterry/google2api
⚠️ 免责声明： 本项目遵循开源协议，仅供技术研究与个人学习交流使用，严禁用于任何形式的商业用途与非法倒卖。
✨
核心功能特性

🔄 多账户与多模式混合

支持同时并行管理 Google Cloud 凭证与 Antigravity 凭证，多模式透明调度。

⚡ 智能轮换与自动避障

智能轮换账户，遇 429 或 403 自动触发熔断冷却或备选路由映射策略。

📊 动态模型映射与兜底

自定义模型别名映射，支持全局 Fallback 目标模型兜底重定向。

🎛️ 配置热更新与代理连接

修改配置即刻生效，原生支持 HTTP / SOCKS5 代理网络连接。
